Steering: Dose–Response

The causal test: inject the axis vector into one mid-network layer during generation (h′ = h + α·v·‖h‖·0.01) and re-measure the projection with the clean model. Monotone dose–response curves mean the axes are causal handles, not correlates. The α range is calibrated per model to stay inside safe perturbation norms.

How It Works

1 · Calibrate

Contrastive prompts (be warm / be cold …) over 50 train + 15 held-out questions. Axis = normalized difference of mean hidden states, pooled over the last 4 layers with token decay.

2 · Measure

Project any response's hidden states onto each axis → a 5-number personality fingerprint in [−1, 1] per axis. Validated on held-out pairs, – mean accuracy.

3 · Stress-test

– scripted conflict conversations vs – neutral controls per model, permutation tests + FDR, format-subspace removal, per-layer probes, 4-bit recalibration.

4 · Steer

Add the axis vector at one mid-layer during generation, α from −50 to +50 (norm-scaled), re-measure with the clean model. Dose–response slopes with bootstrap CIs.
